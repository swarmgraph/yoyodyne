# Project groups goals

This goal reaches beyond Yoyodyne's first version. It records where the product is going, so that work toward it is designed knowing the destination. The operator chose to add it, in these words, on November 7, 2026, when he decided to develop groups of related projects with one set of management roles.

The v1 non-goals keep one harness to one active product in one repository ([the v1 non-goals](goals/v1-non-goals.md)), and this document does not change that. Work toward this goal may be admitted and designed now. Where that work would run more than one repository in one harness, the v1 non-goal that excludes it has to be amended first, and that amendment is the operator's to decide.

## Goals

- [project-groups] A group of projects, each bound to its own repository, can share one statement of intent and one set of management roles, and deliver work that spans them in an order that keeps every deployed combination of the projects working.
  *Supports: it works on other people's projects.*

# Distributed coordination for team mode: replaced

This file used to hold an early draft of how several machines would share one
repository in team mode. That draft was never adopted, and it has been
replaced by the architect's design,
[working alongside other contributors](designs/working-alongside-other-contributors.md),
which covers the same ground: claiming work across machines, merges by other
contributors, the team pause, what travels between machines, and each item's
budgets. Read that design instead. Where anything still repeats the old draft,
the design is the one that applies.

The old text is still in the repository's history for anyone who needs to see
what it said.
